# 🦥 LazyMate AI — Work Less. Relax More.

**LazyMate AI** is a productivity dashboard designed to make everyday tasks easier. It helps users organize tasks, summarize text, create simple daily plans, and take focused breaks.

Built for the **Slow and Steady** hackathon challenge, LazyMate AI encourages people to work smarter, reduce repetitive effort, and make more time to relax.

## ✨ Features

- ✅ **Task Organizer:** Add, complete, delete, and prioritize tasks.
- 📝 **Text Summarizer:** Create shorter versions of long text using simple JavaScript-based text extraction.
- 🌿 **Easy-Day Planner:** Generate a manageable plan based on available time and energy level.
- ⏱️ **Focus Timer:** Use a 10-minute timer to focus on one task at a time.
- 💾 **Local Storage:** Keep tasks saved in your browser.
- 📱 **Responsive Design:** Use the dashboard on desktop and mobile screens.
- 🦥 **Relaxing Interface:** Enjoy a calming, nature-inspired design.

## 🛠️ Technologies Used

- HTML5
- CSS3

- Browser Local Storage

## 🚀 Getting Started

### 1. Download the project

Download or clone this repository to your computer.

### 2. Open the project folder

The project contains these files:

```text
LazyMate-AI/
├── index.html
├── style.css
├── script.js
└── README.md
```

### 3. Run the website

Open `index.html` in your web browser, or use the Live Server extension in Visual Studio Code.

No backend server or package installation is required.

## 💡 How It Works

1. Add tasks and assign priorities.
2. Track completed tasks from the dashboard.
3. Paste text into the summarizer to extract a shorter version.
4. Choose your available time and energy level to generate a simple plan.
5. Start the focus timer and work at your own pace.

## 🌱 Why Slow and Steady?

LazyMate AI is inspired by the idea that productivity does not mean being busy every second. Small steps, manageable plans, and intentional breaks can make everyday work feel less overwhelming.

## 🔓 Open Innovation

This version uses standard web technologies and browser-based logic without paid AI APIs, making it easy to run, inspect, customize, and extend.

**Transparency note:** The current version does not include a real open-weight AI model. Its summarizer and planner use JavaScript rules. Integrating an open-weight model in a future version could enable genuine AI-powered assistance.
